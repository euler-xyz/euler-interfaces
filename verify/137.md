# Polygon — Deployed Code Verification

Chain ID: 137 · Bytecode-proven: **11/11**

Verification = on-chain runtime bytecode ≡ compile(repo@commit, profile), with the metadata trailer stripped, immutables masked, and the metadata digests of embedded child contracts masked at the offsets the build locates. The block explorer is never in the trust path. This shows runtime correspondence under that normalization, not initialization, governance, immutable configuration or deployment safety. Each proven pin is then diffed against its component's audited baseline — the fixes-included state of the component's most recent audit — so every deployed source delta beyond audited code is shown below as a real diff. Re-run: see the repository README.

**All contracts on this chain are bytecode-proven against their pinned commits.**
